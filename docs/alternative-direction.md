# Alternative version direction

Published site: https://amailab.github.io/rssu-technopark-projects-alt/#/home
Repo: https://github.com/amAILab/rssu-technopark-projects-alt

## Product idea

This version is not a classic dashboard. It should feel like a **command center for a live NTS meeting**:

- fewer decorative landing blocks;
- more operational focus;
- darker, higher-contrast interface;
- current decision / current risk / current resource gap visible first;
- pages behave like modes: Overview, People, Projects, Grants, Meeting.

## Difference from main version

Main version: balanced dashboard + mobile app style.

Alternative version: executive command center:

- darker visual language;
- more compact information density on desktop;
- mobile remains large and card-based;
- NTS flow is the core, not just one page;
- project/resource/grant screens should answer: “what decision is needed now?”

## 3-hour sprint priorities

1. Establish command-center identity.
2. Make home page an operational cockpit.
3. Make navigation feel like mode switching.
4. Rework NTS page around current agenda item.
5. Rework projects as status/decision board.
6. Rework resources as allocation board.
7. Rework grants as pipeline and deadlines.
8. Mobile QA.
9. Backend action readiness.
10. Docs and comparison notes.
